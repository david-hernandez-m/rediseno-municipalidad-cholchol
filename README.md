# Rediseño de Sitio Web - Municipalidad de Cholchol

## 1. Presentación del proyecto

Este proyecto consiste en el rediseño de la página de inicio del sitio web de la Municipalidad de Cholchol, tomando como referencia el sitio actual: https://municholchol.cl/.

El trabajo fue desarrollado como parte de una actividad de FrontEnd, donde se solicita mejorar la experiencia de usuario, la responsividad, la accesibilidad y la interactividad del sitio web. Para esto, se diseñó una nueva propuesta de Home municipal con una estructura más moderna, clara y adaptable a diferentes dispositivos.

Como estudiante de tercer año de Ingeniería en Informática, el objetivo principal fue aplicar conocimientos de HTML, CSS, JavaScript y un framework FrontEnd, en este caso Bootstrap 5, para construir una interfaz más ordenada, funcional y fácil de usar para los vecinos de la comuna.

---

## 2. Problema identificado

El sitio web municipal actual presenta algunos problemas comunes en páginas institucionales, especialmente cuando se visualiza desde dispositivos móviles. Entre los aspectos que se pueden mejorar se encuentran:

- Diseño poco atractivo visualmente.
- Problemas de responsividad en pantallas pequeñas.
- Poca interactividad con el usuario.
- Dificultad para encontrar rápidamente trámites o servicios.
- Falta de retroalimentación visual al interactuar con la página.
- Formularios sin validaciones claras para el usuario.
- Organización visual mejorable.

Debido a esto, se propuso una nueva página de inicio que prioriza la claridad, la navegación simple, la accesibilidad y la experiencia del usuario.

---

## 3. Objetivo general

Rediseñar y reconstruir la página de inicio de la Municipalidad de Cholchol, aplicando buenas prácticas de desarrollo FrontEnd mediante HTML5, CSS3, JavaScript y Bootstrap 5, con el fin de mejorar la experiencia de usuario, especialmente en dispositivos móviles.

---

## 4. Objetivos específicos

- Crear una estructura HTML semántica y ordenada.
- Aplicar un diseño visual moderno y coherente.
- Utilizar Bootstrap 5 como framework principal.
- Implementar una interfaz responsiva para celulares, tablets y computadores.
- Agregar interactividad mediante eventos de JavaScript.
- Validar un formulario de contacto en tiempo real.
- Modificar contenido dinámicamente usando el DOM.
- Aplicar principios básicos de accesibilidad web.
- Separar el código en archivos independientes para mejorar la organización del proyecto.

---

## 5. Tecnologías utilizadas

Para el desarrollo del proyecto se utilizaron las siguientes tecnologías:

### HTML5

Se utilizó para construir la estructura principal del sitio web. Además, se aplicaron etiquetas semánticas como:

- `header`
- `nav`
- `main`
- `section`
- `article`
- `footer`

Estas etiquetas ayudan a organizar mejor el contenido y también mejoran la accesibilidad de la página.

### CSS3

Se utilizó para personalizar el diseño visual del sitio. En el archivo CSS se definieron:

- Colores principales.
- Tipografías.
- Espaciados.
- Tarjetas.
- Botones personalizados.
- Animaciones.
- Diseño responsivo.
- Estilos para elementos dinámicos.

### JavaScript

Se utilizó para agregar interactividad al sitio web. A través de JavaScript se implementaron eventos, validaciones de formulario, modificación dinámica del contenido y animaciones.

### Bootstrap 5

Se utilizó como framework FrontEnd para facilitar el diseño responsivo y el uso de componentes predefinidos. Bootstrap permitió trabajar con:

- Sistema de grillas.
- Navbar responsiva.
- Botones.
- Cards.
- Accordion.
- Modal.
- Formularios.
- Utilidades de espaciado y alineación.

### Bootstrap Icons

Se utilizó para incorporar íconos dentro de la interfaz, mejorando la presentación visual y facilitando la comprensión de las secciones.
